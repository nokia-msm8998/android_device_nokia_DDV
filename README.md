# Device configurations for Nokia 7 plus (B2N)

The Nokia 7 plus (codenamed "B2N") is a mid-range Nokia-branded smartphone running the Android operating system.

## Device specifications
| Basic                   | Spec Sheet                                                          |
| -----------------------:|:------------------------------------------------------------------- |
| CPU                     | Octa-core (4x2.2 GHz Kryo 260 Gold & 4x1.8 GHz Kryo 260 Silver)     |
| Chipset                 | Qualcomm SDM660 Snapdragon 660 (14 nm)                              |
| GPU                     | Adreno 512                                                          |
| Memory                  | 4/6 GB RAM                                                          |
| Shipped Android Version | Android 8.1 (Oreo), upgradable to Android 10, Android One           |
| Storage                 | 64 GB                                                               |
| Battery                 | Li-Ion 3800 mAh, non-removable                                      |
| Display                 | 1080 x 2160 pixels, 18:9 ratio (~403 ppi density), IPS LCD          |
| Camera (Back)           | 12 MP, f/1.8, 25mm (wide), 1/2.55", 1.4µm, dual pixel PDAF & 13 MP, f/2.6, (telephoto), 1/3.4", 1.0µm, AF, 2x optical zoom       |
| Camera (Front)          | 16 MP, f/2.0, 1/3.06", 1.0µm                                        |
