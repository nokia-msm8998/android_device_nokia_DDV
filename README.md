# Device Tree for Nokia 7.2 (DDV)

The Nokia 6.1 (codenamed _"daredevil"_ , TLA _"DDV"_) is a mid-range smartphone from Nokia.
It was released in September 2019.

| Basic                   | Specifications                                                                                                                 |
| -----------------------:|:------------------------------------------------------------------------------------------------------------------------------ |
| CPU                     | Octa-core (4x2.2 GHz Kryo 260 Gold & 4x1.8 GHz Kryo 260 Silver)                                                                |
| Chipset                 | Qualcomm Snapdragon 660 (SDM660) (14 nm)                                                                                       |
| GPU                     | Adreno 512                                                                                                                     |
| Memory                  | 4/6 GB RAM                                                                                                                     |
| Shipped Android Version | 9                                                                                                                              |
| Storage                 | 64/128 GB                                                                                                                      |
| Battery                 | Non-removable Li-Po 3500 mAh battery                                                                                           |
| Display                 | 1080 x 1920 pixels, 19:9 ratio (~400 ppi density)                                                                              |
| Camera (Back)           | 48 MP, f/1.8, (wide), 1/2.0", 0.8µm, PDAF (wide), 8 MP, f/2.2, 13mm (ultrawide), 1/4.0", 1.12µm (ultrawide)                    |
| Camera (Front)          | 20 MP, f/2.0, (wide), 1/3", 0.9µm                                                                                              |
